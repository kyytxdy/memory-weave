# 织忆 · Memory Weave

SillyTavern 长期记忆扩展。移动端优先，玻璃拟态界面。

自动把对话织成记忆，再在需要的时候还给你。

---

## 三层记忆

角色扮演聊久了会失忆。原因通常有两种：要么把全部原文塞进上下文，越聊越贵、最后被截断；要么只保留一份笼统的总结，细节全糊在一起。

这个插件用三层解决：

**时间线 —— 每轮一句话（默认 50 字）**

一轮对话结束，压成一句话记进时间线。写清谁做了什么、结果如何，保留人名和具体动作。粒度细，翻回去能找回「她当时到底说了什么」。

**记录 —— 每 10 轮一段概要（默认 200 字）**

攒够 10 轮，把这段时间线摘要合并成一段完整概要。写清整体走向、关系变化、留下的悬念。用的是已有短摘要而不是重读原文，省 token，也更连贯。

**人物档案 —— 一人一卡**

人多起来，光有时间线不够用：你记得"那天在药房吵了一架"，但想不起来吵架的人是谁、什么立场。人物档案按人建档，一个人一张卡，每轮自动更新，覆盖旧值。

新人物出现时由模型判定重要度，达到门槛才建卡；超过设定轮数没再出现就自动移除，不会越积越多。

三层各有各的位置，注入时全部带上，人物档案排在最前面——当下的关系状态最要紧。

> 两层摘要的思路来自 [Memory Books](https://github.com/dddanny79/SillyTavern-MemoryBooks) 的 Scene / Arc 设计：底层频繁、细粒度，上层低频、捕捉变化，且上层从下层生成而非重读原文。

## 安装

酒馆「扩展 → 安装扩展」，填：

```
https://github.com/kyytxdy/memory-weave
```

手动安装的话，把目录放进：

| 版本 | 路径 |
|---|---|
| SillyTavern | `SillyTavern/public/scripts/extensions/third-party/memory-weave/` |
| TauriTavern | `%APPDATA%\com.tauritavern.client\data\extensions\third-party\memory-weave\` |

TauriTavern 的数据跟着 AppData 走，不在安装目录里。

装完刷新页面，右侧会出现一颗发光悬浮球。

## 界面

| 时间线 | 记录 | 模板 | 设置 |
|---|---|---|---|
| 每轮一句话，按天分组 | 每 N 轮一段概要 | 人物列表 + 模板管理 | 开关与参数 |

三种条目用不同的节点区分：圆点是时间线，青色菱形是大总结，金色菱形是手填的表。点卡片展开编辑和删除。

## 参数

| 项 | 默认 | 说明 |
|---|---|---|
| 时间线间隔 | 1 轮 | 每几轮记一条短总结 |
| 大总结间隔 | 10 轮 | 每几轮合并一段长概要 |
| 注入条数 | 6 条 | 带多少条短总结进上下文 |
| 人物保留 | 10 轮 | 超过这么多轮没出现就移除 |
| 建档门槛 | 重要度 3 | 低于这个分数的新人物不建档，5 最难 |
| 记忆风格 | 档案 | 影响提炼语气：档案 / 日记 / 关系簿 |

大总结固定带最近 2 条，不单独暴露。

**注入条数别调太高。** 一条短总结约 50 字，六条约 200–300 token。设到 20 会明显挤压角色卡和世界书的预算。

## 提示词

### 时间线（每轮 50 字）

```
把下面这一段角色扮演对话压缩成一句话。

要求：
- 50 字左右，最多不超过 70 字。
- 写清谁做了什么、结果如何，保留出现的人名和具体动作。
- 用名字指代，不要用「他」「她」「对方」，否则过几轮就分不清是谁。
- 不复述台词，不评价，不写「接着」「这一轮」「然后」这类过场词。
- 直接输出正文。不要引号、不要标题、不要分点、不要任何解释。
```

「用名字指代」这条是关键。不写它，三天后的记忆里全是「他说」「她笑了」，等于没记。

### 大总结（每 N 轮 200 字）

```
下面是一段角色扮演中若干条按时间排列的短摘要。
请把它们合并成一段完整的概要。

要求：
- 200 字左右，最多不超过 260 字。
- 写清整体发生了什么、人物关系有什么变化、留下了什么悬念。
- 用第三人称客观陈述，不评价，不复述台词。
- 直接输出正文。不要标题、不要分点、不要任何解释。
```

### 输出怎么处理

模型返回后统一清洗：剥掉代码块围栏、首尾引号、`总结：` 之类的前缀、markdown 标记，压成一段。判废条件是「我无法」「抱歉」开头或长度不足 6 字——命中就不写入，不把垃圾存进记忆。

**这一段是上一版最严重的问题。** 旧版按行解析、每行一条、解析失败还有宽松兜底，结果模型一不按格式输出，整段回复就被拆成几十条碎片，全都塞进「其他」分类。现在改成整段接收、整段清洗，单条记录，不再有碎片化的可能。

## 模板

三种形态：

**人物档案**（按人建卡，每轮自动更新）

| 字段 | 位置 | 说明 |
|---|---|---|
| 姓名 | 主体 | 卡片的 key，同名自动合并 |
| 身份 | 主体 | 药房主人 / 护卫 / 学徒 |
| 与我的关系 | 主体 | 收留我的人 / 债主 / 宿敌 |
| 对我的态度 | 主体 | 戒备 / 温和 / 试探 |
| 外貌特征 | 折叠 | 一眼能认出的特征 |
| 说话方式 | 折叠 | 口癖、语气 |
| 最近互动 | 折叠 | 这一轮和他发生了什么 |

**事件档案**（每次新建一条，进时间线）

标题 / 分类 / 涉及对象 / 经过，加时间、地点、关键台词、影响、标签。

**当前状态**（快照，只留最新一条，默认关掉自动更新）

场景 / 在场 / 正在进行 + 气氛 / 我的状态 / 对方状态 / 未了结。

### 人物是怎么建的

每轮对话结束，把最近一轮和字段清单发给模型，要求按这个格式输出：

```
【艾拉】重要度:5
身份：药房主人
与我的关系：收留我的人
对我的态度：表面冷淡，实际处处照应
外貌特征：左手腕一道旧疤，常年系着灰布
最近互动：端着温水上楼，提起周老板问过林染的来历
```

重要度按这个标准判：

| 分数 | 含义 |
|---|---|
| 5 | 主角或贯穿剧情的核心角色 |
| 4 | 有名字、有独立台词、之后大概率还会出现 |
| 3 | 有名字、有明确互动 |
| 2 | 只被顺口提到一次 |
| 1 | 背景路人 |

低于门槛（默认 3）的不建卡，路人不占位置。

**同名合并，不重复建。** 字段增量覆盖：模型这轮没提到的字段保留旧值，不会被清空。一次漏读不该抹掉已知信息。

**超过 10 轮没出现就移除**，轮数在设置里调。判的是「最后一次出现到现在的轮数」，不是按时间或字数。误删可以点撤销找回。

### 为什么不让它写「动机」

字段设计有一条线：**只收对话里能直接观察到的东西。**

身份、外貌、说话方式是别人看得见听得见的。动机、隐藏立场、真实情绪不是——让模型填这些，它一定会编。编出来的内容写进档案，下一轮被当作设定注入，角色就开始按编造的人设演，越走越偏。

这些东西留给时间线和大总结：具体事件里自然带出来的性格，比一个要求模型提炼的字段可靠得多。

### 改成你自己的

`templates/` 下有四份可编辑 JSON：

- `person-card.json` 人物档案（`"entity": true, "keyField": "name"`）
- `state-snapshot.json` 当前状态快照（`"singleton": true`）
- `general-memory.json` 事件档案
- `character-profile.json` 角色档案示例

改完从「模板 → 导入 JSON」导入。也可以在界面里新建：增删字段、调顺序、切主次、开关自动更新。

字段类型：

```json
{ "id": "mood", "label": "气氛", "type": "select", "group": "extra", "options": ["平静", "紧张"] }
```

- `text` 单行
- `textarea` 多行
- `select` 选项（需要 `options`）
- `tags` 标签（回车添加）

## 几个说明

**升级后旧记忆不会自动迁移。** 上一版的条目是碎片化的原文摘录，没法自动修复成一句话总结，硬转只会把噪音带过来。新版从当前楼层往后开始记，旧数据仍留在 `settings.json` 里不显示，设置页点「清空」会一并清掉。

**不想每轮都调模型** 就把「时间线自动记录」关掉，改成想记的时候点「记一条」。手动触发需要至少有一轮新对话。

**大总结依赖时间线。** 如果时间线关掉了，大总结没有素材可合并，会自动跳过。想补历史先点「补全部」，它会按间隔一路补到当前位置。

**换模型可能失败。** 提炼走 `generateRaw`，不行退 `generateQuietPrompt`（两种签名），再不行退截取原文。都不会污染聊天上下文。

**数据存在 `extensionSettings['memory-weave']`**，跟着 `settings.json` 走，按 `角色头像::聊天文件名` 隔离。删扩展目录不会丢数据。

## 控制台

```js
MemoryWeave.open()        // 打开面板
MemoryWeave.weave()       // 立刻总结一条
MemoryWeave.backfill()    // 补齐全部历史
MemoryWeave.fill()        // 立刻重填快照
MemoryWeave.form()        // 手动填表
MemoryWeave.info()        // 当前聊天记了多少
```

`MemoryWeave.info()` 会列出每条快照的模板名、更新时间、已填字段数，排查问题时先看它。
