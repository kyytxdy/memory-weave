# 织忆 · Memory Weave

SillyTavern 长期记忆扩展。移动端优先，玻璃拟态界面。

把对话织成记忆，再在需要的时候还给你。

---

## 它做三件事

**自动编织** —— 攒够一批对话，交给模型提炼成短句记忆，按重要度打分，之后每轮生成前挑最相关的几条注入上下文。不用手动整理，聊着就记下来了。

**填表归档** —— 有些东西模型提炼不出来，但你必须记住：某个角色的底细、一道不能碰的界线、一句原样的台词。用模板填一张表定下来，比让模型猜可靠得多。

**快照覆盖** —— 有一类信息不需要历史，只关心"现在是什么样"：此刻在哪、谁在场、手上还有什么没做完。这类模板设成快照模式，永远只存最新一条，每轮自动从上一轮对话重填，覆盖旧值。打开就是当前状态，不会堆积成一本翻不完的流水账。

前两种进时间线，快照单独在「模板」页。注入时快照排在过往片段前面——当下的状态比上个月的事更要紧。

## 安装

### 从 GitHub 装（推荐，方便更新）

酒馆「扩展 → 安装扩展」，填这个地址：

```
https://github.com/kyytxdy/memory-weave
```

装完刷新页面。

### 手动安装

把整个目录放进第三方扩展目录：

| 版本 | 路径 |
|---|---|
| SillyTavern | `SillyTavern/public/scripts/extensions/third-party/memory-weave/` |
| TauriTavern | `%APPDATA%\com.tauritavern.client\data\extensions\third-party\memory-weave\` |

TauriTavern 的数据跟着 AppData 走，不在安装目录（`D:\TauriTavern`）里。

重启酒馆，进「扩展」面板确认「织忆 · Memory Weave」已勾选。

### 装完之后

- 手机端：右侧会出现一颗发光悬浮球，点它唤出面板
- 也可以在扩展菜单（小魔杖图标）里找「织忆 · 记忆」
- 悬浮球可以拖动，位置会被记住

## 界面

四个页面：

| 时间线 | 记录 | 模板 | 设置 |
|---|---|---|---|
| 所有记忆按天分组，菱形节点是填表的记录，圆点是自动编织的短句 | 只列填过的表，按模板分组 | 模板管理 + 快照实时状态 | 开关、参数 |

点卡片展开操作。记录卡展开后会露出折叠的次要字段。

## 模板

内置两张：

**通用记忆表**（普通模式，每次新建一条）

| 字段 | 类型 | 位置 |
|---|---|---|
| 标题 | 单行（必填） | 主体 |
| 分类 | 选项 | 主体 |
| 涉及对象 | 单行 | 主体 |
| 经过 / 内容 | 多行 | 主体 |
| 时间 / 地点 / 关键台词 / 影响 / 标签 | — | 折叠 |

**当前状态**（快照模式，只留最新一条）

| 字段 | 类型 | 位置 |
|---|---|---|
| 场景 | 单行 | 主体 |
| 在场的人 | 单行 | 主体 |
| 我的处境 | 多行 | 主体 |
| 对方的状态 / 进行中的事 / 备注 | — | 折叠 |

字段有两种位置：`main` 直接显示在卡片上，`extra` 折在「展开更多」里。手机上填表越短越好，所以主体只留三四个。

### 快照是怎么更新的

每轮 AI 回复结束后，插件把**最近四条消息**（也就是刚结束的那一轮）和字段清单一起发给模型，让它按 `字段名：内容` 的格式提取。拿不准的字段模型会整行省略——省略的字段保留旧值，不会被清空。所以你手动改过的内容不会因为模型这轮没读出来就消失。

卡片上显示「更新于 19:06」，精确到分钟。跨天会带上月日。

不想让它每轮都跑？设置里关掉「自动更新快照」，或者点模板卡片上的「自动更新」按钮切成「仅手动」，之后自己按需要点「修改」填。

同一轮不会重复请求——插件记了处理过的消息序号，只有对话继续推进才会再触发。

### 改成你自己的

`templates/` 下有三份可编辑的 JSON：

- `general-memory.json` 通用表
- `state-snapshot.json` 状态快照（注意 `"singleton": true, "autofill": true`）
- `character-profile.json` 角色档案示例

改完从「模板 → 导入 JSON」导入。也可以直接在界面里新建：能增删字段、调顺序、切主次、开关快照模式和自动重填。

内置模板不能原地改，点它会生成一份副本再编辑——这样插件更新不会覆盖你的改动。

字段类型支持四种：

```json
{ "id": "quote", "label": "关键台词", "type": "textarea", "group": "extra" }
```

- `text` 单行
- `textarea` 多行
- `select` 选项（需要 `options: ["A", "B"]`）
- `tags` 标签（回车添加，用 chip 展示）

## 参数

| 项 | 默认 | 说明 |
|---|---|---|
| 每批对话数 | 10 | 攒够多少条触发一次自动编织 |
| 注入条数 | 6 | 每轮带给模型多少条记忆 |
| 记忆风格 | 档案 | 影响提炼语气：档案 / 日记 / 关系簿 |
| 用模型提炼 | 开 | 关掉会退化成截取原文，质量差很多 |
| 自动更新快照 | 开 | 每轮结束按快照模板重填一次 |

**注入条数别调太高。** 每条记忆都占 token，六条大约 200–300 token。设到 15 会明显挤压角色卡和世界书的预算。快照不受这个限制，它有自己的位置。

---

## 数据存在哪

存在酒馆的 `extensionSettings['memory-weave']` 里，和其它扩展设置一起写进 `settings.json`。

记忆按 `角色头像::聊天文件名` 隔离，每个聊天各自一份，互不串味。

删掉扩展前记得先备份——数据在设置文件里，不在扩展目录。

## 几个说明

**自动编织不会回填旧聊天。** 新装上的扩展从当前楼层往后记，历史部分要手动点「整理历史」，它会分批跑完。

**提炼用的模型就是你当前连的模型。** 走 `generateRaw`，不会污染聊天上下文。如果当前模型拒绝执行（有些角色卡会把模型带偏），会退回 `generateQuietPrompt`，再不行就退回本地截取。

**手机上自动编织时不要连点。** 一次编织要等模型返回，面板底部会转圈。

**快照每轮都会发一次额外请求。** 一轮对话 = 一次生成上限 400 token 的小请求。长聊下来开销不小，觉得费就关掉「自动更新快照」，改成需要时手动点「修改」。

**快照字段别贪多。** 模型每轮只有一轮对话作依据，字段越多越容易漏。主体留三四个，其余折进「展开更多」——折叠的字段一样会被填，只是不占版面。

**玻璃效果依赖 `backdrop-filter`。** 老版本 Android WebView 可能不支持，会退化成纯色，功能不受影响。

## 文件

```
memory-weave/
├── manifest.json               扩展声明
├── index.js                    全部逻辑
├── style.css                   界面样式
├── preview.html                独立预览页（双击打开，看 UI 用）
├── preview-app.html            预览页的内层
└── templates/
    ├── general-memory.json     通用模板（可编辑后导入）
    ├── state-snapshot.json     状态快照模板（singleton + autofill）
    └── character-profile.json  角色档案示例
```

`preview.html` 和 `preview-app.html` 只是给你看效果用的，不装进酒馆也不影响运行。可以直接删。

预览页支持 `?view=` 参数直达：`records` / `templates` / `form` / `snap` / `settings` / `expanded`。

## 快捷键

全局挂了个 `MemoryWeave` 对象，控制台能用：

```js
MemoryWeave.open()        // 打开面板
MemoryWeave.form()        // 直接开填表
MemoryWeave.weave()       // 手动编织一次
MemoryWeave.backfill()    // 整理全部历史
MemoryWeave.fill()        // 立刻重填一次快照（不等下一轮）
MemoryWeave.info()        // 看当前聊天记了多少
MemoryWeave.exportTemplate()  // 导出内置模板 JSON
```
